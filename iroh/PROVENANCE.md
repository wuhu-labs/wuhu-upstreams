## The ABI

`include/wuhu_iroh.h` is the whole contract: endpoints made from an Ed25519 secret key and a relay map, each relay with its own auth token (relay only, or relays plus direct UDP; no discovery service, no port mapping), home relay failover (a relay whose connection failed before it was established is passed over as home), per-relay state and direct addresses (the interfaces'), dials by relay URL and direct addresses, connections whose accept hands over the verified caller key, bidirectional streams with QUIC backpressure, path and relay state, `network_change`, and an embedded relay with caller admission (`on_connect` with the client's bearer token, `on_disconnect`) and `disconnect(key)`. Asynchronous calls complete through a callback, exactly once, and can be cancelled.

## Artifacts

- `iroh-<version>-apple.zip`: `CIroh.xcframework` with arm64 slices `macos-arm64` (macOS 14.0 floor), `ios-arm64` and `ios-arm64-simulator` (iOS 17.0 floor). Consumers link `-framework CoreFoundation -framework Security -framework SystemConfiguration`.
- `iroh-<version>-linux-x86_64.tar.gz`: `include/{wuhu_iroh.h,module.modulemap}` and `lib/libwuhu_iroh.a`, built on Ubuntu 22.04 (glibc 2.35 floor), packaged only after `cargo test` (the ABI end to end on localhost) passes. Consumers link `-lgcc_s -lutil -lrt -lpthread -lm -ldl -lc`.
